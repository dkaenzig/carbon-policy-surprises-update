# Updated Carbon Policy Surprises

This repository hosts the updated carbon policy surprises from:

Känzig, Diego R., Michael D. Bauer, and Glenn D. Rudebusch (2026).
*Carbon Pricing and Inflation Expectations.*
Conditionally accepted at The Econometrics Journal.   
Ungated version: https://dkaenzig.github.io/diegokaenzig.com/Papers/bkr_carbon_pricing.pdf

## Data

The surprises are stored in the file  

[carbon-policy-surprises.xlsx](carbon-policy-surprises.xlsx)

The file contains the following variables:

| Variable           | Description                                                                                     |
|--------------------|-------------------------------------------------------------------------------------------------|
| ets_price          | EU ETS price, measured based on the front futures contract                                      |
| elec_price         | EU wholesale electricity price, measured as a weighted average over major European markets     |
| event_day          | Dummy variable indicating ETS policy events                                                     |
| event_desc         | Description of ETS policy event                                                                 |
| cp_surprise_base   | Carbon policy surprise, measured as the EUR change relative to wholesale electricity price     |
| cp_surprise_pct    | Carbon policy surprise, measured as the log change in ETS price                                |
